# Multi-Agent Regulator–Manufacturer Simulator

Streamlit demo accompanying:

> Han Y, Guo Z. *Regulator-Manufacturer AI Agents Modeling for Continuously and Dynamically Evolving Digital Health Technologies*. arXiv:2411.15356, 2024.

**Live demo:** https://nmpa-pccp-sim.streamlit.app

---

## ⚠️ Disclaimer

This demo simulates a **hypothetical** NMPA consultation draft and three **fictional** manufacturer profiles. All regulatory outputs, manufacturer responses, and risk scores are generated by template logic (mock mode) or a generic LLM (real mode) **for illustrative and academic purposes only**.

- Nothing in this app represents the actual position of NMPA, FDA, or any real medical device manufacturer.
- The simulation references real published documents (FDA PCCP final guidance, December 2024; YY/T 1833.5-2024) as contextual anchors, but the simulated "consultation draft" is **not a real regulatory document**.
- Single-shot screenshots stripped of this context may mislead — please cite the arXiv paper and this disclaimer when sharing.

---

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Mock mode runs by default — deterministic, offline, zero cost. To switch to real LLM (`gpt-4o-mini`), set:

```bash
export OPENAI_API_KEY=sk-...
streamlit run streamlit_app.py
```

## Files

- `streamlit_app.py` — UI, animation, math state visualization
- `agent_sim.py` — agent profiles, scenario, LLM backend, deterministic mock fallback
